Claude Code 101 at a Glance

Claude Code is an AI agent: software that interacts with its environment and acts to reach a goal, using an LLM that runs in a loop with tools.

How Everything Plugs into the Agentic Loop

The loop is the engine. Every other concept either feeds the context, provides tools, gates actions or runs work in a separate context. Hover or tap a box, or switch to the kitchen view to see the same ideas as a restaurant kitchen.
