## Accessing Claude

<!-- text: required trigger text; content is inserted from clipboard -->

{{< spoiler text="Claude.ai" >}}

- The primary way most people interact with Claude. Here, you can ask questions, brainstorm ideas, create and edit documents, and a lot more. 
- Claude.ai is ideal for conversations, writing assistance, research, analysis, and creating files.

{{< /spoiler >}}

<!-- text: required trigger text; content is inserted from clipboard -->

{{< spoiler text="Claude Code" >}}

- An agentic coding tool that is designed for developers but can be used for all kinds of file manipulation on your desktop. 
- Claude Code can directly edit files, run commands, and create commits.

{{< /spoiler >}}

<!-- text: required trigger text; content is inserted from clipboard -->

{{< spoiler text="Claude Tag" >}}

- Brings Claude directly into Slack. You can chat with Claude in the AI assistant header from any channel or conversation, or by tagging Claude in threads. 
- When you connect Slack to Claude, Claude searches your workspace's channels, direct messages, and shared files to find the context you need for better responses and research.

{{< /spoiler >}}

<!-- text: required trigger text; content is inserted from clipboard -->

{{< spoiler text="Claude Design" >}}

- Turns ideas into working interfaces. Describe what you want — or start from a sketch or screenshot — and Claude builds an interactive prototype you can refine and hand off to your team. 
- It works inside any conversation with Claude on paid plans, and as a dedicated space at claude.ai/design.

{{< /spoiler >}}

<!-- text: required trigger text; content is inserted from clipboard -->

{{< spoiler text="Claude for Microsoft 365" >}}

- Brings Claude into Excel, PowerPoint, Word, and Outlook as a sidebar, so you can analyze, draft, and edit inside the document you already have open — and carry context from one app to the next.

{{< /spoiler >}}
